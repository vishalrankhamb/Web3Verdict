# Web3Verdict

Web3Verdict enables real-time, decentralized data aggregation through smart contract interactions on a scalable blockchain network.

Web3Verdict is built to be simple and practical, focusing on doing one thing well.

**Why Web3Verdict?**

- Web3Verdict enables real-time, decentralized data
- aggregation through smart contract interactions
- on a scalable blockchain network

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/Web3Verdict.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
